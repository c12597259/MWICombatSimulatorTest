# 消耗品准备时间（第二阶段）

计划模拟的角色汇总分别显示战斗、采集原料、烹饪、冲泡、其他加工和总准备时间。
总准备时间不含战斗；计划顶部总耗时仍为原有战斗耗时，不将不同角色的制作时间相加。

## 数据和操作

- 主电脑配装插件 1.9.0.2 在导入时携带精简的 `productionSnapshot`。接收服务器和上传端无需升级。
- 更新插件后重新导入角色、模拟，并在计划中选择新的历史记录。旧记录不会从服务器补写资料。
- 每名角色以计划中第一次出现的历史记录的专业快照为准；专业等级在制作过程中固定不变。
- 专业配装优先于「全部行动」；存在多个不明确的候选时要求手动选择。
- 专业独立配装的饮料栏优先；「全部行动」使用该专业单独记录的饮料栏。
- 配装未指定的专业工具沿用采集时已装备的工具，衣服等穿戴槽仅使用选中专业配装。
- 专业饮料默认假设提前备好：计算增益，不计算补给时间。可选开启补给估计；没有材料来源时会提示缺项。
- 计划内可更换专业配装、饮料及社区固定百分比；设置按计划、角色保存，不修改历史快照或游戏配装。

## 计算边界

使用游戏数据中的配方、基础行动时间、装备非战斗属性和强化倍率。
房屋、成就、公会实际生效神龛、哞卡来自分类常驻增益；不再叠加当前战斗装备的合计属性。
重新按专业装备和饮料计算速度、效率、等级、采集数量、美食、工匠和浓度。
社区默认采集数量 29.5%、生产效率 19.7%，可以手动调整；个人卷轴和迷宫升级不参与普通生产。

以连续期望计算，不取整行动数。各材料独立采集，不抵扣副产物或战斗掉落。
加工茶按连续期望减少保留的原材料，不把加工产物抵扣其他需求。
暂不抵扣库存，不统计换装操作时间，也不预估制作过程中专业升级带来的加速。
可选的专业饮料补给使用迭代物料平衡处理冲泡自身所需饮料；无法收敛则不给出总值。

专业资料不足、配装装备不可用、等级不足、材料缺少可计算来源时，只显示已知部分并列出原因，
总准备时间和含制作时间的碎片速度留空，不把未知时间当成零。
无新版专业快照的主界面碎片估计保留原有回退算法；计划中明确提示需新记录。

## 主界面碎片成本补充（2026-09-26）

「钥匙碎片时间成本 → 制作明细 / 设置」复用同一专业计算器，按每战斗一小时的消耗量计算。
可以直接调整专业配装、饮料和社区增益，碎片时间与每天碎片数立即更新；设置按角色保存在本机。
主界面的设置与已有计划分别保存，不会反向修改计划或历史快照。
无法计算时显示具体缺项和「—」，不再显示 NaN 或笼统的默认估算标签。

按用户确认，琥珀、紫水晶、石榴石、月亮石、珍珠和太阳石视为游玩期间已准备好的原料，
不计获取耗时，但明确列出所需数量（未检查库存）。宝石粉碎和后续制作时间仍然计算。
此规则同时适用于计划和主界面；其他未知来源仍会阻止完整总时间，不会一律忽略。

## 测试

`npm test` 覆盖专业/全部行动选择、空饮料、工具沿用、强化、常驻增益隔离、浓度、
原料递归、专业饮料预备/自给、重复饮料、未知来源，以及快照隔离和计划设置保存。
本地浏览器验证了导入 → 模拟 → 历史 → 计划、饮料和社区参数变更、刷新后保存、黑暗模式。
