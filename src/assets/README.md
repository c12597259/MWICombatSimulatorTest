# Drop item icons

`drop-items.svg` contains the symbols referenced by the normal and rare drop
tables in `combatsimulator/data/combatMonsterDetailMap.json`.

Source: Milky Way Idle's official item sprite,
https://www.milkywayidle.com/static/media/items_sprite.f58c9476.svg
(retrieved 2026-10-12). Artwork belongs to Milky Way Idle; this project does not
claim authorship of these icons.

`drop-item-icons.json` lists the included symbol IDs. When combat data adds new
drops, refresh both files from the official sprite. Unknown items fall back to
their translated names instead of displaying an empty icon.

`abilities.svg` is the official ability sprite from
https://www.milkywayidle.com/static/media/abilities_sprite.fdd1b4de.svg
(retrieved 2026-10-12), used by the ability picker. Artwork belongs to Milky Way Idle.
